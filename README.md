## Weekly Summary

### Week 1 - HTML Fundamentals
Successfully installed and configured code editors (VS Code and Sublime Text) and verified initial workspace organization.

### Week 2 - Semantic & Multimedia
Built a structured web page utilizing semantic elements ("header", "main", "section"), navigation links, and embedded multimedia.

### Week 3 - CSS Basics
Applied external stylesheets, custom color schemes, the CSS box model, and media queries to ensure layout responsiveness across screen sizes.

### Week 4 - JavaScript Basics and DOM Manipulation
Implemented dynamic element modification, real-time clock updating, interactive task management, state-persisted dark mode, and client-side form validation.

### Week 5 - Javascript Functions and Bootstrap
Integrated the Bootstrap framework to implement responsive grid systems, a mobile-friendly navbar, an image carousel, and structured card components.

### Week 6 - API & Client Storage
Utilized browser local storage for user preferences and integrated the OpenWeatherMap API to fetch and display real-time weather data dynamically.

### Week 7 - MiniFullStackStarter
Developed a full-stack application using Node.js, Express, and Mongoose with MongoDB Atlas, implemented full CRUD operations, and deployed the live project to Render.
